# agentglass for herdr

[agentglass](https://github.com/BjoernSchotte/agentglass) inside [herdr](https://herdr.dev): the agentglass TUI as a
popup, "Open in agentglass" for the focused agent, `agentglass://` links, workspace cost, opt-in sidebar tokens for cost
and alerts, and a notify recipe for the alerts herdr cannot see.

Work in progress — the first release (v0.1.0) ships together with the agentglass release that carries CLI contract 1.

```sh
herdr plugin install BjoernSchotte/agentglass-herdr
```
